# ESP32-CoCo3-PRO
A Tandy Color Computer 3 emulator 6809 / 6309 cycle-accurate running bare-metal on an ESP32-S3-WROOM-1 N8R8, with VGA output, USB keyboard / mouse / gamepads, SD card storage, Wi-Fi and more!

# Test disks and example tape

| File | Contents |
|---|---|
| `CPUTEST.DSK` | detects the CPU (MC6809 / HD6309) and checks HD6309 instruction results |
| `JOYTEST.DSK`, `JOYTEST2.DSK` | joysticks, buttons, mouse, Hi-Res interface and keyboard test |
| `TERMINAL.DSK` (`TERMINAL.TXT`) | 9600-baud terminal for the RS-232 Pak (BREAK = back to BASIC) |
| `VIDE40DF.DSK`, `VIDE80DF.DSK` | blank double-sided disks, 40 and 80 tracks |
| `TESTCART.ROM`, `TESTGMC.ROM` | ROM cartridge test and bank-switched (Game Master type) cartridge test |
| `RAMTEST/` | MMU and RAM test (512 KB / 2 MB / 4 MB) with its source (`ramtest.asm`) and build scripts |
| `HELLO.CAS` | small BASIC program on tape: `CLOAD` then `RUN` |

# ESP32-CoCo3-PRO v1.0
Author: Luc Dion 2026-10-26

First public release.

**Install:** copy `ESP32-CoCo3-PRO_v1.0.FLH` (or `.BIN`) into the `/FLASHNOW` folder of the SD card and
power the board. The firmware is checked, written to the inactive flash slot and started; the
previous version stays available (F12 > SYSTEM > PREVIOUS VERSION).

**Highlights**
- Tandy Color Computer 3: MC6809 / HD6309, GIME 1986 / 1987, 512 KB - 4 MB RAM, all video modes.
- Floppies (.DSK), DriveWire 4 (Becker port, built-in server or PC over Wi-Fi), VHD hard disks.
- Cassette: .CAS and .WAV playback, .CAS recording, fast load.
- Multi-Pak, ROM cartridges, Orchestra-90, Game Master Cartridge, CoCo PSG, RS-232 Pak, CoCo SDC.
- USB keyboard, mouse (Hi-Res interface), gamepads; Wi-Fi modem, web page, PC shared folder.
- Save states, boot screen, screen saver, AUTORUN, hardware health page, F9 problem reports.

Documentation: `docs/GUIDE_EN.md` · `docs/GUIDE_FR.md`. CoCo ROMs are not included.
